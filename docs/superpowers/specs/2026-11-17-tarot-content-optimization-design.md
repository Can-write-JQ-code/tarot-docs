# 塔罗教程视频教学优化版设计

## 目标

在不修改 `塔罗牌系统教程与全资料汇编.md` 的前提下，制作 `塔罗牌系统教程与全资料汇编_视频教学优化版.md`，使其从资料汇编升级为可用于零基础视频备课的分层教程。

## 已确定的读者与成果

主要读者为零基础学习者，辅以卡在死背牌义阶段的爱好者。课程毕业成果不是“看完即精通”，而是能在模板辅助下完成并复盘一次有牌面证据、共同牌义校准、替代解释、现实核查和行动收尾的三牌解读。

## 方案选择

采用“保留八篇资料手册、另建学习主路径”的最小重构方案。曾考虑扩展到31集以及全面重写，但不采用：当前问题是证据边界、规则冲突和教学负荷，不是资料或集数不足。

## 内容约束

- 原文件只读；所有写入仅发生在指定副本和本设计/计划文件。
- 保留原文有效的版本考据、R.I.T.E.、牌意光谱、语境修正、案例、复盘工具和视觉教具。
- 区分可观察事实、个人解释、流派理论和可另行验证的历史/科学事实。
- 不用塔罗诊断疾病、怀孕、法律结果或第三方心理；文献断语仅作存档，不作为行动建议。
- 缺失元素、大小牌比例、逆位和应期只能产生假设，不能脱离语境独立定论。
- 第14—21式详细补写在外文原版未提供前标为外部来源待核。
- 不执行 Git 提交，不修改视频工程，不新增软件依赖。

## 结构

保留八篇，增加【主线】【查阅】【进阶】【文献存档】导航。24集保持六大模块精神：边界与提问、SOP与单牌、结构骨架、主题牌组、三牌综合、选修拓展。全量辞典、复杂牌阵、应期与完整逆位表转为查阅或进阶。

## 验证

核对原文件SHA-256不变；副本存在且内容不同；24集与学习目标齐全；高风险旧措辞已清理或有明确存档边界；代表案例完整呈现观察、候选、反馈、暂定结论、行动和复盘；Markdown标题、表格与代码围栏结构可读。
