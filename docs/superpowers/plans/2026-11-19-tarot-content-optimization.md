# 塔罗教程内容优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不制作视频、不拆分资料库的前提下，将现有文档优化为口径一致、安全边界清楚、基础考核可靠且具备后续训练路径的零基础教程。

**Architecture:** 只修改现有总文档，保留其“主线＋查阅＋进阶＋文献存档”结构。优先修正会误导学习者的内容，再补强教学闭环；不新增视频脚本，不承诺“大师认证”，不删除有研究价值的历史文献记录。

**Tech Stack:** Markdown、Kimi Code Read/Edit/Grep、Git diff。

**Spec:** `塔罗牌系统教程与全资料汇编_视频教学优化版.md` 及本轮审阅中确定的安全、事实、教学和考核要求。

## Global Constraints

- 保留RWS主线、全正位优先、逆位后置和现有八篇结构。
- 区分可观察信息、个人解释、流派理论和现实核查。
- 医疗、怀孕、法律、财务及第三方心理不得由牌面作确定判断。
- 文献存档可以保留历史断语，但必须与可参与牌义校准的内容明确分开。
- 不把课程观看进度、收费、神秘体验或从业年限写成“大师”证明。
- 不制作24集逐字稿，不新增独立学员版或视频项目文件。

## Review Focus

- 文献标签错标可能使普通牌义无法参与校准：检查愚人、魔术师、权杖五和权杖九的相关栏目。
- 存档中的医疗断语可能被误当作现实建议：检查所有明确疾病、怀孕和伤病情境均有禁用边界。
- 绝对化语言可能推翻前文的候选解释原则：检查“必然、精准、即刻改写、宇宙支持”等高风险句式。
- 评分规则可能允许关键能力不足仍通过：检查第2、3、5、6、7项的最低分要求。
- L4/L5可能只有称号而无训练闭环：检查训练、证据、外部评价和复测要求是否明确。
