# Tarot Teaching Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有零基础课程蓝图补齐为可训练、可评分、可复测的独立三牌实占课程，并提供后续进阶路径。

**Architecture:** 只修改现有视频教学优化版，保留八篇资料汇编结构。在第二篇增加课程能力等级、练习系统与评分规则，在第七篇补齐全流程三牌案例和修正案例，并修正审稿发现的关键过度确定表述。

**Tech Stack:** Markdown 文档；使用 Read/Edit/Grep 核查，无代码依赖。

**Spec:** 用户前一轮审评结论及本轮“直接修改目标文件、不得修改另一份讲稿”的要求。

## Global Constraints

- 仅修改 `塔罗牌系统教程与全资料汇编_视频教学优化版.md` 和本计划文件。
- 不承诺预测准确率，不把个人联想写成外界事实。
- 不把一次三牌作业等同于独立熟练实占，不以阅读完成替代能力考核。
- 保留原有资料层级、文献存档和进阶内容，不大规模删减资料。

## Review Focus

- 三牌毕业成果与四牌旧示范并存时，必须明确各自层级，避免考核错位。
- 评分须同时考察内容质量、现实边界和独立完成条件，不能只检查栏目齐全。
- 78牌训练须可执行、可记录，并区分视频示范与课后覆盖。
- 诱导性、诊断性和绝对化措辞须改成候选解释及反馈筛选。
- 预测复盘须保留未支持解释和失败案例，避免事后附会。
